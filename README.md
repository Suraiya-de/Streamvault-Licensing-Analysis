# StreamVault Licensing Analysis ($14M Content Acquisition Case Study)

## Project Overview
An end-to-end data acquisition, cleaning, and financial analysis pipeline built to advise **Kwame Boateng (VP of Content Acquisition)** ahead of the October 31st board licensing review. Using live movie metadata and credits from the TMDb API, this analysis evaluates whether StreamVault should allocate its **$14M licensing budget** toward **franchise bundles** or **standalone hits**, comparing performance across all release years against a post-2000 window.
